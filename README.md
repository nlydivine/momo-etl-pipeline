# Project Overview

This project implements a secure REST API for managing Mobile Money (MoMo) SMS transaction records. The API parses transaction data from an XML file and provides CRUD operations (Create, Read, Update, Delete) through REST endpoints.

The project also demonstrates the use of Data Structures and Algorithms (DSA) by comparing the performance of Linear Search and Dictionary Lookup when retrieving transaction records.
